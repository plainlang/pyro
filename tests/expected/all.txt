***definitions***


- :Widget: is a thing with a name.
  - the name is a non-empty string.

- :Registry: holds many :Widget:.

***implementation reqs***

- Implement in Python 3.
- Use :UnitTests: with pytest.

***test reqs***

- Run :ConformanceTests: with pytest.

***functional specs***

- Create a :Widget: from a name.

  ***acceptance tests***

  - Creating a :Widget: named "a" yields a :Widget: with name "a".
  - An empty name is rejected.

- List all :Widget: in the :Registry:.

  ***acceptance tests***

  - An empty :Registry: lists nothing.

- Delete a :Widget: by name.

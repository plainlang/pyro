***definitions***


- :Widget: is a thing with a name.
  - the name is a non-empty string.

- :Registry: holds many :Widget:.

***implementation reqs***

- Implement in Python 3.
- Use :UnitTests: with pytest.

***test reqs***

- Run :ConformanceTests: with pytest.

***functional specs***

# create-widget
A :Widget: is created from a name.

# list-widgets
All :Widget: items in the :Registry: are listed.

# delete-widget
A :Widget: is deleted by name.
